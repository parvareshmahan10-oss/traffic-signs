# تمرین علائم راهنمایی و رانندگی کویت

وب‌سایت تمرین چندگزینه‌ای برای ۱۵۶ علامت راهنمایی و رانندگی کویت (برگرفته از سایت ادارهٔ کل راهنمایی و رانندگی، moi.gov.kw).

## امکانات
- **تمرین بر اساس دسته**: هشدار، ممنوعیت و حق تقدم، اجباری، اطلاعاتی، تابلوهای مکمل، عملیات جاده‌ای، بزرگراه
- **تمرین میکس**: همهٔ دسته‌ها با هم (علائم جدید و ضعیف‌تر کمی بیشتر می‌آیند)
- **مرور اشتباه‌ها**: علائمی که درصد اشتباه بیشتری داشتی اول می‌آیند؛ هر علامتی که در مرور دوباره غلط بزنی، چند سؤال بعد دوباره پرسیده می‌شود. وقتی ۳ بار پشت سر هم درست جواب بدهی از لیست مرور خارج می‌شود.
- **آمار**: درصد اشتباه هر علامت، مرتب‌شده از بیشترین
- زبان گزینه‌ها: انگلیسی + فارسی / انگلیسی / فارسی / عربی / انگلیسی + عربی
- کلیدهای ۱ تا ۴ برای جواب و Enter برای سؤال بعد (روی کامپیوتر)
- خروجی/ورود فایل پیشرفت (برای انتقال بین دستگاه‌ها)

پیشرفت در `localStorage` مرورگر ذخیره می‌شود؛ هیچ سرور یا حسابی لازم نیست.

## انتشار روی GitHub Pages
1. یک ریپازیتوری جدید بساز (مثلاً `kuwait-traffic-signs`).
2. همهٔ فایل‌های این پوشه را آپلود کن (`index.html`، `style.css`، `app.js`، `signs.js` و پوشهٔ `signs/`).
3. در ریپازیتوری: **Settings → Pages → Build and deployment → Source: Deploy from a branch**، شاخهٔ `main` و پوشهٔ `/ (root)` را انتخاب کن و Save بزن.
4. بعد از یکی دو دقیقه سایت روی `https://<username>.github.io/kuwait-traffic-signs/` بالا می‌آید.

## ساختار فایل‌ها
| فایل | توضیح |
|---|---|
| `index.html` | صفحهٔ اصلی |
| `style.css` | ظاهر (حالت روشن/تاریک خودکار) |
| `app.js` | منطق آزمون، آمار و مرور |
| `signs.js` | فهرست علائم: کد، دسته، نام انگلیسی/فارسی/عربی، مسیر تصویر |
| `signs/` | تصویر هر علامت با نام کد آن |

برای اصلاح یا اضافه کردن یک علامت، کافی است یک ردیف در `signs.js` اضافه/ویرایش کنی و تصویرش را در `signs/` بگذاری.
